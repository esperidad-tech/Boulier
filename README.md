# L'école du boulier

Apprendre le boulier japonais (soroban) et le calcul mental au boulier (anzan), en 7 étapes avec des petits jeux.

1. Les perles qui comptent
2. Les grands nombres
3. Ajouter tout simplement
4. Les petits amis (les amis de 5)
5. Les grands amis (les amis de 10)
6. Enlever
7. Le boulier dans la tête (photo du boulier, flash anzan)

Chaque prénom est une sauvegarde : on clique dessus et on reprend là où on s'était arrêté.
La progression est gardée dans le navigateur de chaque appareil.

Tout tient dans un seul fichier : `index.html`.
